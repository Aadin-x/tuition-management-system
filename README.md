# Tuition Management System

A web application to manage students and fee details for a small tuition centre.
Developed by Aadin.

## Features
- Secure admin login with hashed passwords
- Add, view, edit and delete students
- Search students by name or roll number
- Dashboard with total students, paid and pending fees

## Tech Stack
Python, Flask, SQLite, HTML, Bootstrap

## How to run
1. Install Python 3
2. `pip install -r requirements.txt`
3. `python create_admin.py` (create the admin account)
4. `python app.py`
5. Open http://127.0.0.1:5000
